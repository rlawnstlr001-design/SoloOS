# 07. 제작 계획, 리스크, 열린 질문

## 1. 기술 아키텍처 (Godot 4.4, GDScript)
- **sim/ (순수 시뮬레이션)**: 노드 의존 없는 결정론적 로직. 시드 RNG, 상태는 직렬화 가능. 헤드리스 단위 테스트 가능.
- **view/**: 보드 렌더, UI, 연출. sim 상태를 구독만 한다.
- **data/**: 구조물·유물·퍽·오멘·변종·헤럴드·노드를 JSON/리소스로 정의 (밸런싱을 데이터 수정만으로).
- **저장**: sim 상태 스냅샷(JSON) → 매 낮 시작 자동 저장, 클라우드 세이브(Steam).
- **밸런스 하네스**: 헤드리스로 수천 시드를 봇 정책(무작위/빛 몰빵/방벽 몰빵/혼합)으로 돌려 클리어율, 지배 전략, 난이도 곡선을 측정.
- 현재 저장소의 서바이버 프로토타입(`scripts/`, `scenes/`)은 폐기하고 위 구조로 재시작한다.

## 7. 확정된 결정 (Decision Log)
1. 장르: 턴제 영토 방어 빌더 로그라이트 (Base Building + Pixel).
2. 적: 유닛이 아닌 규칙 기반 오염(+7 헤럴드).
3. 가격 $14.99, 정식 출시, Steam 우선, 간체 중국어 포함 다국어.
4. 구조: 원정 3스테이지 + Lattice 37노드 메타 지도.
5. 엔진: Godot 4.4. 결정론적 sim 레이어 분리.

## 8. 열린 질문 (사용자 확인 필요)
1. **아트 제작 능력**: 픽셀아트 경험 정도와 현실적인 속도 (M2에서 계측하지만 사전 정보가 계획 정확도를 높임).
2. **실제 주당 투입 시간**: 30시간이 지속 가능한가?
3. **현금 예산 한도**, 현지화/오디오 외주 의향.
4. **퍼블리셔 피칭 의향**과 지식재산권 관련 선호.
5. 가칭 **DIMHOLD** 괜찮은지, 다른 방향의 이름 선호가 있는지.
6. Steam 등록/세금: 한국 거주자의 개인/사업자 등록 방식 (정산 시 세금 서류 필요).
7. 내부 해상도 640x360 vs 320x180 선택 (타일 가독성 프로토 후 결정).

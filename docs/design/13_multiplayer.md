# 13. 멀티플레이 — 2인 각자 무대 협동 (2026-10-20)

## 결정 (개발자 선택)
- 모드: **각자 무대 협동**. 각자 자기 트랙과 보드를 지키고, **한 사람이라도 무너지면 둘 다 패배**. 보스는 두 무대에 동시에.
- 접속: **IP 직접 접속** (서버 비용 없음). 방 코드·Steam 친구 초대는 나중 과제.

## 플레이 방법
1. 둘 다 같은 버전의 게임을 켜고 메뉴 → 도깨비 디펜스 → 준비 화면의 **'멀티'** 탭.
2. 방장: **'방 만들기'** → 상태 줄에 내 IP가 뜬다. 친구에게 알려 준다.
3. 친구: IP 칸에 방장 IP 입력 → **'접속'** (또는 Enter).
4. 방장이 난이도를 고르고(친구 화면에도 반영) **'협동 시작'**.
5. 판 안에서: **V = 동료 무대 보기/돌아오기**, **G = 동료에게 골드 20 보내기**. 왼쪽 위 초록 줄에 동료의 웨이브·요괴 수·골드가 보인다.

### 연결이 안 될 때
- **같은 와이파이/공유기**: 방장의 `192.168.x.x` 같은 내부 IP로 바로 된다. Windows 방화벽이 Godot을 물어보면 '허용'.
- **인터넷 너머**: 둘 중 하나.
  - 방장이 공유기에서 **UDP 24680** 포트를 방장 PC로 포워딩하고, 친구는 방장의 공인 IP로 접속.
  - 둘 다 **Radmin VPN** 또는 **Tailscale**에 가입해 같은 가상 네트워크에 들어간 뒤 그 IP(26.x / 100.x)로 접속 — 포트 설정이 필요 없어 가장 쉽다.

## 동작 방식 (scripts/net.gd)
- Godot `ENetMultiplayerPeer`, 포트 24680, 최대 2명. 네트워크 노드는 `/root/Net`에 살아서 장면을 다시 불러와도(R) 연결이 유지된다.
- **각자 자기 무대만 시뮬레이션**한다 (락스텝이 아님 → 부동소수점 동기화 문제 없음).
- 같은 경험을 위한 동기화:
  - 시작: 방장이 시드·난이도를 보내고, 둘 다 그 시드로 **막별 요괴·보스를 똑같이** 뽑는다. 소환·합성 결과 같은 운은 각자.
  - 웨이브: **방장이 웨이브 마스터.** 각자 웨이브 시간이 끝나고(보상 카드가 있으면 고른 뒤) "끝"을 알리면, 둘 다 끝났을 때 다음 웨이브를 동시에 시작한다. 기다리는 동안에도 남은 요괴는 계속 움직인다.
  - 속도·일시정지: 방장만 바꾸고 친구에게 따라간다.
  - 결과: 한쪽이 패배하면 상대도 즉시 "동료의 무대가 무너졌습니다"로 끝. 둘 다 최종 보스를 잡으면 협동 승리.
  - 스냅샷: 0.2초마다 자기 무대 요약(유닛 칸·종류·등급, 요괴 id·종류·위치·체력)을 보내고, 받은 쪽은 자기 무대 오른쪽(+38)에 동료 무대를 그려 요괴 위치를 보간한다.
- 엽전·마을 장식·해금은 **각자 자기 저장 파일**에서 적용된다.
- 연결이 끊기면 남은 사람은 혼자 계속한다.

## 검증
- `tests/mp_test.gd`: 같은 PC에서 Godot 두 개(방장/친구)를 헤드리스로 띄워 실제 접속을 시험.
  ```
  godot --headless --path . -s tests/mp_test.gd -- host 12 play
  godot --headless --path . -s tests/mp_test.gd -- client 12 play
  ```
- 결과 (2026-10-20):
  - 둘 다 봇 플레이 12웨이브: 막별 요괴·보스 **완전히 일치**, 웨이브 차이 최대 1(스냅샷 지연), 스크립트 오류 0.
  - 친구 쪽 방치(idle): 친구가 4웨이브에 무너지자 방장도 즉시 "동료의 무대가 무너졌습니다"로 종료.
  - 창 모드 두 개로 화면 확인: 멀티 탭(내 IP 표시), 판 안의 동료 무대 미러링, 동료 상태 줄.
- 아직 확인 못 한 것: **실제 인터넷 너머 두 PC**에서의 접속과 지연. 친구와 처음 할 때 확인 필요.

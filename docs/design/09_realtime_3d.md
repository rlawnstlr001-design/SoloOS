# 09. 방향 전환: 실시간 + 로우폴리 3D (v0.3, 2026-10-19)

## 결정 (사용자 선택)
- 시간: **완전 실시간 (일시정지 가능)**
- 비주얼: **로우폴리 3D** (Thronefall/Dorfromantik 계열). "픽셀 아트" 목표는 폐기.
- 배경 피드백: 2D 턴제 프로토타입이 "1차원적", 글씨 깨짐, 건물 역할 설명 없음.

## 구현 방식 (v0.3 프로토타입)
- **시뮬레이션은 그대로**: sim/game_state.gd(규칙 v0.2, Python 참조 구현과 parity 테스트 통과)를 시계로 구동.
  - "펄스" = 기존의 Dusk 1회. 1배속 기준 15초마다 1회, 일시정지/1/2/3배속.
  - 펄스 사이의 연속성은 연출로 표현: 오염 높이가 부드럽게 자람, 해가 기울며 붉어지고 어두워짐, 균열 회전, 위험 피라미드 흔들림.
- 행동력(LP) 제거: 실시간에서는 자원만이 제약. 카드(영토 확장)는 펄스당 1회.
- 3D는 전부 코드로 만든 단순 도형(육각 기둥, 원뿔, 상자) + 빛/그림자/글로우. 손으로 그린 에셋 없음.
- 조작: 우클릭 드래그 회전, 휠 확대, WASD/QE 이동, 버튼 → 지도 클릭으로 건설, 버튼 설명 툴팁.

## 근거와 반론 (스파링 기록)
- 시각: 로우폴리 3D 방어는 Thronefall(리뷰 2.3만, 긍정 96%)처럼 시장 근거가 강하다. 아트 경험이 없어도 도형+셰이더로 일관된 스타일을 만들 수 있다. **찬성 근거 강함.**
- 시간: 완전 실시간 오염 확산 방어의 대표작 Creeper World 3/4는 리뷰 3~4천 수준의 틈새. **시장 근거 약함.**
  "편하게 즐기는" 목표와 충돌할 수 있어 일시정지를 필수로 유지.
- 지금의 "실시간"은 틱 기반이라 진짜 연속 시뮬레이션(유체 확산)은 아니다. 이걸로 충분한지는 플레이로 판단.

## 미해결 / 다음 단계 후보
1. 실시간 리듬 검증: 15초 펄스가 적절한가? 지루하면 짧게, 버거우면 길게. 12펄스=3분 스테이지는 짧을 수 있음.
2. 진짜 "실시간 행동"이 필요한가: 펄스 사이에 움직이는 존재(오염 괴물 Dimling, 헤럴드 보스)가 있어야 시간의 입체감이 생긴다 (03 문서 5절, 3절).
3. 3D용 튜토리얼 (현재는 2D 튜토리얼로 규칙 학습).
4. 밸런스: LP 제거로 자원만 제약 → 시뮬레이션 재보정 필요 (08 문서 기준 경제가 이미 느슨함).
5. 성능: 빛 구조물이 많아질 때 Compatibility 렌더러 조명 수 제한 점검.

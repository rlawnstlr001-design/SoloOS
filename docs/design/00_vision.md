# 00. 비전

## 한 줄
**"방어선이 곧 영토다."** 빛나는 픽셀 왕국을 턴제로 넓혀 가며, 번지는 오염(Dim)을 한 칸씩 밀어내는 로그라이트 영토 방어 빌더.

## 컨셉 요약
- 육각 보드에서 매일 타일 카드를 드래프트해 영토를 확장하고 구조물을 짓는다.
- 해 질 녘(Dusk)마다 오염이 규칙에 따라 번진다. 번지는 결과는 **미리 전부 예고**되어, 패배는 운이 아니라 판단의 결과다.
- 영토를 넓힐수록 수입은 늘지만 지켜야 할 전선도 길어진다.
- 한 번의 원정(Expedition)은 3개 스테이지, 약 35~40분. 원정에서 번 Ember로 영구 지도(Lattice)의 노드를 하나씩 되살린다.

## 디자인 기둥
1. **영토는 자산이자 부채.** 모든 확장은 수입과 노출의 교환이다.
2. **읽을 수 있는 압박.** 오염의 다음 확산은 항상 화면에 보인다. 숨겨진 랜덤으로 죽지 않는다.
3. **반복 없는 15~30시간.** 수치 그라인드 대신 변종·지역·키퍼·유물의 조합으로 깊이를 만든다.
4. **편안한 긴장.** 턴제, 언제든 저장, 되돌리기 제한 없는 일시정지, 부드러운 난이도 모드.
5. **한 장으로 설명된다.** 빛 대 어둠의 시각 구도가 캡슐 이미지와 첫 3초 트레일러 그 자체다.

## 타깃과 포지셔닝
- 타깃: 전략/빌더/로그라이트 팬, 코지-긴장 균형을 즐기는 플레이어. 서구권 + 간체 중국어권.
- 가격: $14.99 (시장 조사에서 히트 최빈 가격). 플랫폼: Windows, Steam Deck 검증 목표, Linux 선택.
- 시장 근거: Base Building+Pixel 코호트 히트율 6.7%, 히트작 중앙가격 $11.3 / 플레이타임 약 21시간.

## 차별화 (대비표)
| 작품 | 방어 방식 | DIMHOLD 차이 |
|---|---|---|
| Gnomes | 턴제 TD, 유닛 배치 | 적 유닛이 없다. 오염 확산 대응이 전부. 배치 노동 없음 |
| Border Pioneer | 덱빌딩+타워 | 지배 전략(스팸)이 오염 적응 시스템으로 억제됨 |
| Creeper World 3/4 | 유체 확산 방어(RTS) | 로그라이트+영토 확장+구조물 시너지, 턴제, 현대적 UX |
| Thronefall | 미니멀 실시간 TD | 턴제 시뮬레이션, 장기 메타 지도 |

## 비목표 (하지 않는 것)
실시간 전투, 멀티플레이, 절차 생성 내러티브, 인앱 결제, 오픈월드, 대사 음성.

## 시장 조사에서 가져온 설계 제약
- 반복 불만(29%) → 변종 로테이션, 적응 시스템, 지역별 규칙 변화, 모듈식 오멘.
- 지배 전략 불만 → 적응(Familiarity) 시스템: 한 도구만 쓰면 오염이 내성을 가짐.
- 마이크로매니지먼트/UI 불만(15%) → 건물은 한 번 지으면 유지, 일괄 명령, 되돌리기 1회.
- 난이도 절벽 불만 → 예고 시스템 + 난이도 단계(Dusk Level) 곡선 + Gentle 모드.
- 메타 그라인드 패딩 불만 → 해금 중심, 수치 보너스 총합 +10% 상한.
- 런 중간 저장 불가 불만 → 턴 단위 자동 저장, 언제든 종료.

## 프로토타입 통과 기준 (M0, 약 2주)
색 사각형만으로 1개 스테이지(12일)를 구현하고 아래를 만족해야 다음 단계로 간다.
- [ ] 지인 3명 이상이 한 스테이지를 끝낸 뒤 "한 판 더" 의사를 보인다.
- [ ] 예고 화면만 보고 다음 확산을 80% 이상 맞춘다 (이해 가능성 검증).
- [ ] 확장 드래프트에서 "고민되는 선택"이 일 평균 1회 이상 나온다 (관찰/인터뷰).
- [ ] 어떤 한 가지 도구만으로 3스테이지를 거의 깨지 못한다 (지배 전략 점검, 시뮬레이션).
- [ ] 불통과 시 컨셉 폐기 또는 규칙 수정. 매몰비용 금지.

# 06. 연출, UI, 오디오, 접근성, 현지화, 업적

## 1. 아트 방향
- 내부 해상도 640x360 (픽셀 퍼펙트, 정수 배율; 320x180은 육각 타일 가독성 한계로 보류 [가설]). 타일 가로 32px.
- 팔레트 28색 이내: **빛 = 따뜻한 호박/금색, 오염 = 인디고/청록/보라**, 지형은 채도를 낮춘 중간색.
- 가독성 규칙: 변종은 색이 아니라 **형태 패턴**으로 구분(둥근/각진/점점이/비늘/나선). 강도 1~3은 오버레이 패턴 밀도로.
- 시그니처 연출: Dusk에 어둠이 타일을 서서히 덮는 셰이더, Bloom이 빛으로 번지는 반대 연출, 정화 시 타일이 "켜지는" 순간.
- 캡슐 이미지: 중앙의 빛나는 영토를 어둠이 에워싸는 구도, 로고는 "DIM"의 D에 램프.

### 아트 물량 (스프라이트 기준) [가설]
| 항목 | 수량 | 비고 |
|---|---|---|
| 지형 타일 | 10종 x 3 변형 | 오염 강도 오버레이 별도 |
| 구조물 | 30종 x Lv II = 60 | Lv II는 색/장식 변형 |
| 오염 오버레이 | 5변종 x 3강도 | 타일셋/패턴 |
| 헤럴드 | 7종 x 3~4 프레임 | 2단계 포함 |
| 키퍼/동료 초상 | 6 + 12 + 헤럴드 7 | 반신 초상 32x32 |
| UI 아이콘 | 약 150 | 자원/상태/능력 |
| 이벤트 일러스트 | 12~16 | 스테이지 간 컷 |
| 환경 생물 | 6종 | 간단한 루프 |
| VFX | 약 25 | 정화, Dusk, 균열 등 |
직접 제작 기준 약 450~600 스프라이트. 개발 시간의 35~40% 예상 [추정]. 부족하면 구조물 Lv II 색 변형으로 대체.

## 2. UI/UX
- 화면: 중앙 보드 + 좌측 정보 패널(자원/LP) + 우측 선택 패널(카드/건설) + 하단 타임라인(Dawn/Day/Dusk) + 예고 토글.
- **예고 오버레이**: 칸마다 현재 강도 → 예측 강도 화살표. 호버 시 "무엇이 이 칸을 밀고 있는지" 근거를 숫자로 표시 (Pressure vs Guard).
- 일괄 건설(드래그), 템플릿 복사(같은 구성을 다른 칸에), 한 번 키로 End Day. 되돌리기는 낮 동안 무제한.
- 키보드/마우스 + 컨트롤러 지원, Steam Deck 대응. 단일 클릭 중심, 휠/단축키 선택.
- 튜토리얼은 첫 원정에 단계별 말풍선, 설정에서 끄기 가능. 최초 10분 이탈 방지가 핵심 지표.

## 3. 오디오
- 음악: 지역별 테마 6 + Haven 1 + 헤럴드 전투 1 + Aureole 1 + 엔딩 1 = 약 10곡. 낮/밤은 같은 곡의 레이어(낮: 멜로디, Dusk: 저음 드론).
- 효과음: 약 80종 (배치, 정화, 확산, 경고, 능력, UI). 대사 음성 없음.
- 조달: 라이선스 에셋 + 일부 직접 제작 [미정]. 예산 초안: 음악 $300~$800 / SFX 팩 $100.

## 4. 접근성
- 색맹: 변종/상태는 패턴+아이콘 병기, 팔레트 보정 모드.
- 텍스트 크기 3단계, 모션 감소, 화면 흔들림 끄기, 연출 건너뛰기(Dusk 빠르게).
- 컨트롤 재매핑, 소리 시각 보조(경고음에 아이콘).

## 5. 현지화 계획
- 첫 출시 8개 언어 목표: 영어, **간체 중국어**, 한국어, 일본어, 독일어, 프랑스어, 스페인어, 러시아어 (Steam 점유와 히트 상관 기반).
- 모든 문자열은 키 기반(CSV/PO). 중국어/일본어 폰트 서브셋 포함, 픽셀 폰트 대안 준비.
- 방식: 기계번역 + 원어민 검수 [비용 미정]. 간체 중국어는 검수 우선.
- 텍스트가 길어지는 언어(독/러)를 위해 UI 레이아웃에 여유 40%.

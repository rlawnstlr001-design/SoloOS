# 11. 도깨비 디펜스 디벨롭 (2026-10-19)

## 출발점
- 장난감 2(도깨비 디펜스)가 재미 기준을 처음 통과: "재밌어. 좋다. 이제 하나씩 디벨롭하자." (10 문서)
- 이제부터 이 문서가 기준이다. 이번 단계 범위는 **비주얼 아트 + 게임 디자인** (개발자 선택). UI·사운드는 다음 단계.
- 원칙: 한 번에 하나씩 바꾸고, 바꿀 때마다 봇 테스트(tests/toy2_test.gd)와 직접 플레이로 재미가 유지되는지 확인한다.

## 1. 비주얼 아트 방향
- 스타일: 로우폴리 3D, 전부 코드로 만든 도형 + 빛 (09 문서 유지). 손으로 그린 에셋은 아직 없다.
- 무드: **"보름달 뜬 조선 시골 마을 마당에 요괴가 몰려오는 밤"**. 차가운 달빛(남색) vs 따뜻한 불빛(초롱·창호지).
  요괴는 보라·청록 계열 발광, 아군은 오방색(빨강·파랑·노랑·흰색·검정)으로 대비.
- 가독성 규칙 (카메라가 위에서 내려다보므로 머리 위 실루엣이 가장 잘 보인다):
  1. 유닛은 **머리 실루엣**으로 구분: 도깨비 = 뿔·덥수룩한 머리, 궁사 = 전립+붉은 상모, 포수 = 패랭이, 무당 = 높은 관+깃털,
     물귀신 = 얼굴 가린 긴 머리, 해태 = 갈기+외뿔, 구미호 = 여우 귀+꼬리, 저승사자 = 넓은 흑립(갓), 염라대왕 = 면류관.
  2. **계열 = 발밑 원판 색** (도깨비 빨강 / 신수 금색 / 무인 파랑 / 주술 보라). **등급 = 발밑 고리 색과 빛** (일반 흰색 → 전설 금색).
     전설은 공중에 뜨고, 영웅(레시피)은 머리 위에 금빛 고리.
  3. **투사체는 유닛마다 다르다**: 화살(궁사), 탄환+꼬리(포수), 회전 방망이(도깨비), 방울 고리(무당), 물방울(물귀신),
     금빛 포효(해태), 여우불(구미호), 회전 부적(저승사자). 범위 공격은 맞은 자리에 고리가 퍼진다.
  4. **적은 웨이브 구간마다 외형이 바뀐다** (지금은 외형만, 능력은 같음): 1–4 잡귀, 5–8 달걀귀신, 9–12 도깨비불, 13–16 그슨대,
     17–19 장산범. 보스는 이무기(10), 불가사리(20, 쇠붙이 몸). 현재 웨이브의 요괴 이름을 HUD에 표시.
- 손맛 연출: 공격할 때 유닛이 앞으로 튀어나감, 피격된 요괴가 부풀며 움찔, 처치 시 연기, 소환 시 계열색 연기,
  합성 시 빛기둥, 영웅 탄생 시 큰 빛기둥+고리. 대기 중에는 숨쉬기, 요괴는 뒤뚱거리며 걷는다.
- 무대: 흙 마당 + 돌 발판 24칸, 돌 테두리 길, 홍살문과 장승(요괴 입구), 보라 소용돌이, 초가집·기와집(창호지 불빛),
  소나무, 장독대, 돌담, 석등, 청사초롱(흔들림, 실제 광원), 반딧불.

### 구현 (이번 단계에서 완료)
- `scripts/toy2_art.gd`: 모든 모델·무대·투사체·효과. 게임 규칙과 게임용 난수(rng)를 건드리지 않는다.
- 검증: 봇 밸런스 결과가 아트 작업 전과 **완전히 동일** (방치 0/8 · 건너뛰기 2/8 · 무작위 6/8 · 판단 8/8) → 규칙 변화 없음.
  메시 캐시 덕에 헤드리스 테스트 시간은 86초 → 55초로 오히려 줄었다.

### 아트 다음 후보
- 유닛 레벨별 외형 변화(등급이 오를수록 장신구·무기 강화), 요괴 사망 시 "저승행" 연출, 카메라 흔들림(보스 피격).
- UI 테마(한지·단청 색, 카드 일러스트) — UI 단계에서.
- 실제 아트 에셋으로 교체할 때도 `toy2_art.gd`의 함수(make_unit / make_enemy / make_projectile)만 바꾸면 된다.

## 2. 게임 디자인 디벨롭 (제안 — 개발자 선택 필요)

### 지금 구조의 빈 곳 (장난감 2 기준)
1. **콘텐츠가 얕다**: 유닛 8, 영웅 4, 유물 7 → 두세 판이면 거의 다 본다.
2. **적이 체력만 다르다**: 웨이브마다 요괴의 성질이 같아서, 풀 구성과 배치가 "적에 반응하는" 선택이 되지 못한다.
3. **강화 버튼이 단순하다**: 가장 많은 계열을 올리는 게 거의 항상 정답 (봇도 그렇게 해서 8/8).
4. **소환 연타가 최적**: 손은 바쁜데 고민은 적다. 골드가 생기면 바로 소환하는 것 외의 선택지가 약하다.
5. **판이 끝나면 남는 게 없다**: 메타 성장 없음 → C(영웅 원정 지도)가 담당할 부분.

### 제안 목록
| ID | 내용 | 해결하는 빈 곳 | 크기 |
|---|---|---|---|
| **G1 요괴 성질** | 요괴 5종에 고유 성질 부여: 잡귀(기본), 달걀귀신(분열: 죽으면 작은 귀신 2), 도깨비불(빠름·물리 저항, 부적/여우불에 약함), 그슨대(장갑: 약한 공격 무시), 장산범(돌진: 가끔 순간 가속). 다음 웨이브 예고 표시. | 2 | 중 |
| **G2 계열 단계 시너지** | 필드 위 같은 계열 수 2/4/6명이면 계열 효과 발동 (도깨비: 뚝딱 확률↑, 신수: 보스 피해↑, 무인: 사거리↑, 주술: 둔화·처형 강화). 인접 시너지와 별개. | 3, 4 | 소 |
| **G3 콘텐츠 확장** | 유닛 8→14 (계열당 3~4: 예 두억시니·산신·사명대사·바리공주·불개·처용), 영웅 4→8, 유물 7→16. | 1 | 중 |
| **G4 카드 다양화** | 2웨이브 보상에 새 카드: 유닛 각성(특정 유닛 하나 강화), 저주 유물(강한 효과 + 대가), 상점(골드로 특정 유닛 구매). | 1, 4 | 중 |

| **G6 메타** | 판 사이 해금·성장 → C(영웅 원정 지도)로 연결. | 5 | 대 |

### 추천 순서
1. **G1 + G2를 먼저.** 둘 다 이미 있는 재미(풀 고르기·배치)를 더 깊게 만든다. G1은 "이번엔 무엇을 풀에 넣을까"를 적에 반응하게 만들고,
   G2는 "어떤 계열로 갈까"라는 목표를 준다. 새 콘텐츠를 만들지 않아도 판마다 선택이 달라진다.
2. 그다음 G3(콘텐츠) — G1·G2 규칙 위에서 유닛을 늘려야 새 유닛마다 역할이 생긴다.
3. G4·G5는 G3와 함께 조율. G6은 C 단계.

### 검증 방법
- 봇: 현재 판단 봇이 8/8인데, G1·G2 후에는 "계열을 고르는 봇"과 "아무 계열이나 강화하는 봇"의 승률 차이가 커져야 한다.
- 사람: 개발자 플레이 후 "판마다 다른 빌드를 해봤는가?"를 묻는다.

## 3. 아트 패스 후 플레이 피드백 (2026-10-19)
- 아트: 유닛 구분·등급 가독성·화면 복잡도 모두 합격. **캐릭터 디자인은 더 디벨롭** (다음 아트 단계).
- **계열 강화 미사용** → 지금의 "+15% 버튼"은 존재감이 없다. 강화를 스킬·시너지와 엮어 눈에 보이는 변화로 바꿔야 한다.
- **20웨이브는 짧다** (3배속 몇 분) → 웨이브 수와 막 구조 확장 (G5 확정).
- **MP 스킬** 요청 → 합성으로 강해진 유닛(영웅 등급 이상)이 MP를 모아 설화 기반 스킬 사용 (신규 G7).
- **콘텐츠 확장 필수** (G3 확정), 역사·설화 조사를 바탕으로 유닛·요괴·보스를 늘린다 (G1 요괴 성질과 함께).
- 결정: G1 + G3 + G5 + G7을 한 묶음으로 진행, 강화 개편 포함. 상세는 [12 문서](12_folklore_content.md).

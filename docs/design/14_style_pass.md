# 14. 캐릭터 퀄리티 — 1단계 스타일 패스 (2026-10-20)

## 배경
- 개발자 질문: "유닛이나 요괴 퀄리티 디벨롭은 어떻게 해야 할까?"
- 판단: 게임 카메라에서 유닛 하나는 손가락 한 마디 크기로 보인다. 디테일보다 **실루엣·비율, 셰이딩, 동작, 색 규칙**이 퀄리티를 좌우한다.
- 로드맵: ① 코드 모델 스타일 패스(이번) → ② 영웅 1·보스 1 시범 모델로 제작 방식 비교(AI 3D 생성 + Blender 정리 / 외주) → ③ 영웅 13 → 보스 7 → 자주 보는 유닛 → 요괴 순으로 교체.
  모델 교체는 `toy2_art.gd`의 `make_unit` / `make_enemy`만 바꾸면 된다.

## 이번에 바꾼 것 (scripts/toy2_art.gd, 규칙 변화 없음)
1. **셀(툰) 셰이딩 + 림라이트**: 모든 재질에 `DIFFUSE_TOON`·`SPECULAR_TOON`과 약한 림을 적용 → 빛이 단계로 끊겨 만화 같은 질감.
2. **외곽선**: 캐릭터(유닛·요괴·보스 마디)의 불투명 부품에 뒤집힌 껍질(inverted hull) 외곽선. 눈·끈처럼 아주 작은 부품은 제외해 얼굴이 뭉개지지 않게 했다.
3. **꼬마 비율**: 사람형 유닛 32종의 머리(얼굴·모자 포함)를 1.32배로 키움 → 약 2.5등신. 모자·관 실루엣이 멀리서도 구분된다.
4. **동작**
   - 소환: 작게 나타났다가 살짝 튕기며 커짐 (pop-in).
   - 조준: 표적 쪽으로 부드럽게 돌아봄 (순간 회전 → 보간).
   - 공격: 앞으로 튀어나가며 납작해졌다 늘어남 (squash & stretch).
   - 피격: 요괴가 하얗게 번쩍임 + 부풀기.
   - 죽음: 줄어들며 가라앉고 돌며 사라짐 (+ 연기).
5. **방망이 도깨비 재디자인** (12 문서 1절 원칙 5): 뿔과 호랑이 가죽 옷(오니풍)을 없앰.
   붉은 갈색 피부, 쪽빛 저고리와 흰 바지(대님·짚신), 덥수룩한 큰 갈기 머리, 큰 눈과 넓은 입(작은 송곳니), 혹 달린 나무 방망이.
   도깨비 대왕은 뿔 대신 금관과 붉은 저고리, 금 방망이.

## 검증
- 봇 밸런스(보통, 3시드): smart 3/3 · noup 0/3 — 스타일 패스 전과 수치가 완전히 같다 (규칙 변화 없음).
- 스크린샷: 유닛 갤러리 3장, 요괴 갤러리, 일반 플레이 화면에서 외곽선·비율·도깨비 새 외형 확인.

## 남은 것 / 다음
- 성능: 외곽선은 캐릭터 그리기 횟수를 약 2배로 늘린다. GTX 1660 Ti에서는 문제없지만, 저사양 대비 '외곽선 끄기' 옵션 후보.
- 요괴 쪽은 외곽선·피격·죽음만 받았다. 요괴별 비율·실루엣 다듬기는 다음 단계에서.
- ② 시범 모델 비교 (바리공주, 불가사리 후보).

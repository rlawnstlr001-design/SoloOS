## 1. 보드
- 육각 격자(axial 좌표). 스테이지 보드 = 반지름 4 (61칸). 중심에 Hearth(난로).
- 칸 상태: **Fog**(미탐색) / **Wild**(탐색됨, 소유 아님) / **Lit**(내 영토) / **Blight**(오염 강도 1~3) / **Scar**(파괴됨, 재건 불가).
- 시작: Hearth + 반지름 1 링(7칸) Lit. 반지름 4 바깥 링에 **Rift(균열)** 3개(D0 기준)가 보인 채 시작.
- Rift = 오염의 영구 발생원. 매 Dusk 인접 칸에 압력을 주며, 봉인(Seal)할 수 있다.

## 2. 타일 카드와 확장 (드래프트)
- 매일 아침 타일 카드 3장 제시 (지형 + 특성). 1장을 골라 Lit 칸에 인접한 Wild/Fog 칸에 놓으면 그 칸이 Lit가 된다.
- 놓지 않은 카드는 버려지거나, 보관함(Satchel, 1장)에 저장. 리롤 = Lumen 2.
- 오염 가까이(Rift 방향) 놓을수록 칸의 수확량이 높다 (**위험-보상 경사**: 가장자리 칸 수확 x1.5).
- 확장은 무료 행동이다. 대신 확장된 칸은 오염 압력의 대상이 된다 (핵심 긴장).

## 3. 자원
| 자원 | 용도 | 주 공급원 |
|---|---|---|
| **Lumen (L)** | 고급 구조물, 능력 사용, 리롤, 특성 | Lantern 계열, Lamp Press, 우물 |
| **Matter (M)** | 건설/수리 | Gatherer's Camp, 지형 보너스 |
| **Folk (F)** | 하루 노동력 = 행동 수(LP) | Hearth(4), Cottage(+2), 이벤트 |
- **LP (Labor Points)**: 하루 행동 횟수 = 보유 Folk 수. 건설/업그레이드/능력 사용마다 1~2 LP.
  (건물에 인원을 일일이 배치하지 않는다 → 마이크로매니지먼트 최소화)
- 시작값 [가설]: L 8, M 10, F 4.
- 메타 화폐: **Ember** (스테이지 종료 시 지급). 인게임에서는 쓰이지 않는다.

## 4. 빛과 방어 (Light / Guard)
- 칸의 **Light(0~3)**: 구조물과 Hearth가 주변 칸에 퍼뜨린다 (겹치면 최댓값).
  - Hearth: 자기 3 / 인접 2 / 거리2 1
  - Lantern: 자기 2 / 인접 1
- **Guard** = Light + 방벽 보너스 (Palisade +1, Rampart +2, 지형 보너스는 변종별).
- 구조물은 건설 후 유지된다. 매일 재배치할 필요가 없다.

## 5. 오염 시뮬레이션 (Dusk 해결) — v0.2
오염 칸은 **강도 1(Taint) / 2(Gloom) / 3(Void)**. Rift는 강도 3 고정 발생원.

**압력(Pressure)**: 오염 칸 s가 인접 칸 t에 주는 기여 = `강도(s) + 변종·지형 보정(t)` (0 이하는 무시).
칸 t의 총 압력 = **이웃 기여의 최댓값** (+1, 기여하는 이웃이 4개 이상일 때). Rime Reach, Spore 씨앗도 같은 방식으로 기여로 합류.

**Guard(t)** = Light + 방벽 보너스 + 지형 보정(언덕은 Murk/Rime에 +1) - (Hollow 반경 2 내 -1), 최소 0.

**확산 규칙** (Dusk에 모든 칸 동시 계산):
1. `총압력(t) > Guard(t)` → `강도(t)+1` (최대 3). 강도 0→1은 신규 오염(지배 이웃 변종 계승).
2. 오염 칸에서 `총압력(t) ≤ Guard(t)` 이고 `Guard(t) > 강도(t)` → `강도(t)-1` (정화).
3. 강도 3인 점등 칸이 다음 Dusk에도 3이면 **Scar** (구조물 파괴, 재건 불가, Sunwell로 복구).
4. 강도 2 이상 칸의 구조물은 가동 정지(빛도 끊김).
5. 확산 후: Brazier 인접 Rime -1/Spore -2, Rust 구조물 HP -1, Hollow 씨앗(3일마다), 붕괴 판정, Sunwell 복구.

**적응(Adaptation)**: 최근 3 Dusk의 계열별(Light/Flame/Ward) 정화 기여 비율이 60% 초과 + 절대량 6 이상이면 다음 2 Dusk 동안 그 계열 기여 -1. **Hearth(코어) 빛은 집계·내성에서 제외.** 하루 전 경고.

**예고(Forecast)**: 위 규칙은 결정론적이다 → 다음 Dusk 결과를 칸마다 표시. 기본 1회, Watchtower +1, Gentle +2.
무작위는 타일 카드, 오멘(하루 전 공지), 포자 낙하 위치(시드 해시, 공지)뿐.

**유지비(v0.2)**: 새벽에 빛 구조물 N개당 Lumen ceil(N/2) 지불. 부족분은 Hearth에서 먼 구조물부터 그 Dusk 동안 소등.

## 6. 턴 구조
**아침(Dawn)** → 생산 정산, 오멘 공지, 타일 카드 3장 제시
**낮(Day)** → 드래프트 1회(무료), 건설/업그레이드/능력(LP 소모), 인사이트 선택, 동료 이벤트. 낮 동안 무제한 되돌리기(드래프트 추첨 제외)
**Dusk(해 질 녘)** → 해결 순서: ① Rift 방출 ② 변종 틱(Murk→Rime→Spore→Rust→Hollow 고정) ③ 헤럴드 이동 ④ 오멘 효과 ⑤ 붕괴 판정 ⑥ 승패 판정. 연출은 건너뛰기 가능.
- 자동 저장: 매 낮 시작 시. 종료 후 이어하기 지원.
- 한 낮 목표 소요: 45~75초 [가설].

## 7. 스테이지 승리/패배 (v0.2)
- **승리 A**: 12일째 Dusk 이후 Hearth 생존.
- **승리 B (조기)**: Rift **2개 봉인** 즉시 승리 (봉인된 Rift는 영구 제거, 봉인 하나마다 방출원이 줄어 생존에도 이득).
  봉인: Sunwell이 Rift에서 거리 ≤2(2 LP, 5 Lumen). 시뮬레이션에서 범위 3 기준 도달률 2% → 상향 필요 여부는 사람 테스트로 판단.
- **패배**: Hearth 칸 Scar 또는 Folk 0.
- **Ember** [가정식, 조정 예정] = 생존일x2 + 점등 면적/4 + 종료 점등 칸x3 + 봉인x25 + 승리 30 + 조기 승리 20 + **Frontier Ember(Hearth 거리 ≥3 점등 칸 x2.5 / Dusk)**.

## 8. 원정(Expedition) = 런
- 원정 = **3개 스테이지** (약 35~40분). Stage1 표준, Stage2 변종+1/오멘 강화, Stage3 헤럴드 또는 엘리트 오염.
- 스테이지 사이 **캠프**: 유물 3개 중 1개 선택, 폴크 재편(최대 3명 생존자 이월), 인사이트 확정, 다음 스테이지 환경 미리보기.
- 이월: 키퍼, 키퍼 레벨, 인사이트, 유물, 동료, 트레이드. 보드/건물/자원 대부분은 초기화(자원 50% 이월).
- 패배 시: Ember 60% 획득 (Gentle 100%). 그 원정은 종료, Haven으로 복귀.

## 9. Lattice (메타 지도, 캠페인)
- 37노드 육각 지도 = 중심 Aureole 1 + 6개 지역 x 6노드. 바깥(ring3 18) → ring2 12 → ring1 6 → 중심.
- Haven은 바깥 가장자리. 노드를 하나 원정으로 되살리면 Haven 지도에 점등/구조물이 추가되어 보인다 (영구 지도 확장).
- 인접한 점등 노드(또는 Haven)가 있어야 다음 노드 도전 가능. 안쪽일수록 난이도 상승.
- 메인 클리어: ring1 노드 4개 이상 점등 후 Aureole 도전. 진 엔딩: ring1 6개 전부 + 동료 아크.
- 설계 목표 플레이타임 [가설]: 메인 클리어 10~14h, 전체 37노드 25~35h, 이후 Dusk Level 반복 플레이.

## 12. 구현 의사코드 (Dusk)
```
for each tile t: pressure[t] = sum(strength(s->t) for s in neighbors(t) if s.blight)
for each tile t in order: 
    if pressure[t] > guard[t]: t.intensity = min(3, t.intensity+1)
    elif t.blight and guard[t] > t.intensity and pressure[t] == 0: t.intensity -= 1
apply variant extras (rime line jump, spore seeds, rust hp, hollow sink)
move heralds; apply omen; collapse(intensity==3 && was3_last_dusk) -> Scar
```

## 13. 알려진 설계 취약점 (v0.1 시점 기록; 1·2는 v0.2에서 처리됨)
1. **Lantern 스팸 지배 가능성**: Lantern은 자기 Light 2 / 인접 1. 오염 압력이 인접 칸 강도 합계이므로, 단일 이웃(강도 1)의 압력 1은 Guard 1을 못 넘는다 → 값싼 Lantern 격자만으로 초반 확산이 거의 막힐 수 있다.
   대응 후보: 압력 공식 상향(강도²), Lantern Light 인접 0.5 단계화, Rift 방출량 시간 증가, 변종별 Light 효율 차(Hollow/Rime에서 빛 약화), 적응 시스템 임계값 하향. 봇 하네스로 "Lantern만" 정책 클리어율이 50%를 넘으면 규칙 수정.
2. **구조물 HP 기본값 미정**: Rust 규칙상 모든 구조물에 HP가 필요 → 기본 3 [미정].
3. **"한 칸 한 구조물" 긴장의 크기**: 영토가 19~25칸일 때 방어 칸 비율이 적절한지(30~45% 목표) 측정 필요.
4. **예고 결정론으로 인한 풀린 퍼즐**: 낮 동안 완벽한 계산이 가능 → 카드/오멘/씨앗 무작위와 적응으로 충분한지 플레이테스트로 확인.
5. 이 문서의 수치는 아직 한 번도 시뮬레이션되지 않았다. 신뢰하지 말 것.

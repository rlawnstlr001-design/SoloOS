# PixelRogue — 로드맵 (Steam 출시 목표)

## 전제 (검증 필요)
- 솔로 개발, 주 30시간+, 6~9개월, 아트/사운드 직접 제작
- 엔진: Godot 4.4 (GDScript). 320x180 내부 해상도, 정수 배율
- 장르: 로그라이트 (1차 프로토타입은 오토어택 아레나 서바이버)
- 수익 가정은 가정일 뿐: 출시 시 위시리스트 수가 매출을 좌우함

## 단계
| 단계 | 기간 | 완료 기준 |
|---|---|---|
| 0. 프로토타입 | 1~2주 | 핵심 루프가 5분 플레이로 "한 판 더"가 나오는지 지인 3명 이상 테스트 |
| 1. 킬/폐기 결정 | 2주차 | 재미 신호 없으면 컨셉 변경. 매몰비용 금지 |
| 2. 버티컬 슬라이스 | ~2개월 | 최종 아트 스타일 1스테이지, 무기/패시브 10+, 메타 진행 1종 |
| 3. Steam 페이지 오픈 | ~3개월차 | 스토어 페이지 + 트레일러. 위시리스트 수집 시작 (Coming Soon은 출시 전 수개월 필요) |
| 4. 콘텐츠 확장 | 3~6개월차 | 스테이지 3~4, 무기/패시브 40+, 보스, 세이브/설정/컨트롤러 |
| 5. 데모 + 넥스트 페스트 | 6~7개월차 | 데모 공개, 위시리스트 목표 달성 여부 점검 |
| 6. 출시 | 8~9개월차 | 위시리스트 미달이면 출시 연기가 합리적 |

## Steam 체크리스트
- Steamworks 가입, 앱 등록비 $100 (매출 $1,000 이후 환급), 세금/은행 정보
- 스토어 페이지 심사, 출시 전 최소 대기기간 확인
- GodotSteam 연동(업적 정도만), Windows 빌드 우선, Linux 선택

## 위험
1. 스코프 팽창 — 단계 4 이전에 콘텐츠 추가 금지
2. 서바이버 장르 포화 — 차별화 훅(테마/메커닉 1개)을 단계 1 전에 정해야 함
3. 직접 제작 아트 병목 — 단계 2에서 아트 속도를 측정하고 스코프에 반영
4. 마케팅 0 — 개발 시간의 20~30%를 위시리스트 확보에 배정
